# Atelier de Képultum

L'atelier d'écriture du livre-jeu *Aventures en Képultum* : passages en formulaires, catalogues (ennemis, objets, Mots, informations), graphe, aperçu jouable, vérifications et publication du jeu en un fichier HTML.

Ce dépôt ne contient que le programme. Le livre lui-même est enregistré dans un dépôt privé séparé (`livre.json` et le dossier `images/`), auquel l'atelier accède avec un jeton d'accès personnel saisi une fois par ordinateur et conservé dans le navigateur.

- `index.html` : l'atelier.
- `lecteur-modele.html` : le modèle du jeu publié (l'atelier y insère le livre au moment de la publication).
